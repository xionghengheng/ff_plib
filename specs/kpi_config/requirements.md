# KPI 配置 model 与 DAO

以用户给出的三张表 DDL 为准，沿用现有 DAO 风格及此前直接实现的要求，不增加数据库变更或 HTTP handler。

1. 当读写人员配置时，系统应支持新增、按 ID 更新、全部或按类型查询人员列表。
2. 当读写人员月配置时，系统应支持新增、按月份与人员更新/单点查、按月份查询列表，保留人员姓名及类型快照。
3. 当读写月度目标时，系统应支持新增、按月份更新及单点查询。
4. 当指标未设置时，系统应保留 NULL，与 0 区分；金额目标单位为分，百分比为百分数。
5. 当执行 DAO 操作时，新增使用 Create、更新使用 Updates(map)、查询使用参数化 Raw SQL；业务校验、时间及操作人由调用方提供。
